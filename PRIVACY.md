# Privacy Policy for Discord Status

Last updated: August 21, 2026

Discord Status is a Chrome extension that shows supported browser activity as Discord Rich Presence through the Discord Status Companion app.

## Data Stored Locally

Discord Status stores extension settings, selected mode, detected activity, and diagnostic logs locally in Chrome storage.

This may include:

- enabled site settings
- backend URL
- selected status mode
- recent detected activity title/state
- local diagnostic logs used for troubleshooting

## Data Sent To The Companion App

When enabled, the extension sends the current activity to the Discord Status Companion app running on the same computer, usually at `http://localhost:17654`.

The companion app forwards the current activity to Discord through Discord's local Rich Presence connection.

## Data Collection

Discord Status does not sell user data.

Discord Status does not use browsing activity for advertising.

Discord Status does not send browsing activity to an external analytics server.

Discord Status does not collect passwords, payment information, personal communications, or authentication credentials.

## Third Parties

The only intended third-party service involved in normal use is Discord, because the companion app updates the user's Discord Rich Presence status.

Supported websites such as YouTube, Netflix, Spotify, GitHub, ChatGPT, Google Meet, Twitch, Crunchyroll, Hotstar, Google, and Wikipedia are only inspected locally in the browser to detect activity for the user's status.

## User Control

Users can disable the extension, clear their current activity, clear extension logs, or uninstall the extension at any time.

Users can also stop the Discord Status Companion app to stop Discord Rich Presence updates.
