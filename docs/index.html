Need a hand?

Quick answers.

Do I need both downloads?

For browser activity, yes: install the Chrome extension and one companion installer. The companion alone is enough for supported desktop apps and custom activities.

Which Windows file should I choose?

Use the Setup executable for a normal install. Use the MSI only for managed or scripted deployments.

Why is Discord disconnected?

Open Discord desktop, start the companion, and use Reconnect in the extension or companion. The local endpoint is http://localhost:17654.

Where is my activity sent?

The extension sends activity to the local companion over localhost. The companion sends it to Discord desktop. There is no remote activity server.
