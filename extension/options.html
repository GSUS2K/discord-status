Discord Status Settings

Tune the local backend, polling cadence, monitored sites, and extension logging.

Backend
Discord Rich Presence must run on the same computer as the Discord desktop app. For most setups, keep this as http://localhost:17654.
Discord application/client ID is configured in backend/.env, not here. If you change DISCORD_CLIENT_ID, restart the backend.
Detection
How often the extension asks supported tabs to refresh. Two seconds is the safe minimum; Discord timers continue counting between updates.
Old tab activity is removed after this many seconds without a fresh report.
Clean mode keeps playback time out of the status text so Discord's own progress bar stays readable. Detailed mode restores the older, more verbose timer text.
Choose which built-in detectors can run. New sites require code support, not just a setting.
Privacy & Rules
Use platform-only mode for privacy. Private mode clears Discord activity.
