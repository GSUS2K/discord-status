Get your first status running

The extension reads browser activity. The companion connects it to Discord and also detects approved desktop apps such as VLC.

  1. Keep Discord desktop open and install one companion package for your operating system.
  2. Install this extension, then enable the sites you want to share.
  3. Use Auto Detect for normal use, Active Tab Only for privacy, or Manual for a status you write yourself.
